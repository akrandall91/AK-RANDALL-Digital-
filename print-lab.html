Questions you’re likely to ask

Answered before you order.

What if the family doesn’t have a printed program yet?

We can build Memory Light from a photo plus the name and memorial text directly, and the obituary link — no program cover required.

What if there’s no online obituary live yet?

The tap needs a live link to program correctly, so we’ll need the obituary page published before we can finalize that piece — the light box and panel can still be produced in the meantime.

How long does a Memory Light order take to arrive?

48 hours from when we have the program cover (or photo + text) and the obituary link. Ask about rush options if a service is on very short notice.

What happens if a name or detail is misprinted?

Flag it as soon as it’s noticed and we’ll correct and reprint the panel — confirming the name, dates, and text before production avoids this in the first place.

Does Mini Tap work on every guest’s phone?

Nearly all modern smartphones support tap natively. Each unit also ships with a printed QR code as a fallback for anyone whose phone doesn’t read it.

Can we reprogram a Mini Tap ourselves without help?

Yes — that’s the design. A free how-to card walks any staff member through it; it takes under a minute with a standard smartphone, no app install required.

Is there a minimum order or ongoing fee?

No monthly fee on either product. Memory Light is priced per unit; Mini Tap has volume pricing but no subscription — you own what you buy.

Can the light box or panel be swapped or updated later?

The panel can be reordered if a family wants an additional photo produced later. The light box itself is reusable across panel changes.
